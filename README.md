# Анімація — 6 анімацій для рілсів з однієї команди

Плагін для Claude Code. Кожна команда збирає вертикальну анімацію 1080×1920 у Remotion і рендерить MP4.

| Команда | Що робить |
|---|---|
| `/notifications` | локскрін, на який падають сповіщення про замовлення |
| `/iso-map` | ізометрична схема процесу: будиночки, дорога, машинка |
| `/before-after` | до і після зі світною шторкою |
| `/laptop` | ноутбук відкривається, на екрані — продукт |
| `/day-counter` | «ДЕНЬ N» і календар із галочками |
| `/globe` | 3D-глобус із дугами між містами |

## Встановлення
У Claude Code:
```
/plugin marketplace add burmistrovaalina1303-create/animacia
/plugin install animacia@animacia
```

## Як користуватись
Відкрий Claude Code у папці для рілсів (краще не на робочому столі з iCloud) і напиши, наприклад:
```
/globe Відправили замовлення в 12 країн, старт — Львів
```
Без тексту команда зробить приклад, який легко переробити під себе.

Потрібні: Node.js 18+ і Claude Code.
